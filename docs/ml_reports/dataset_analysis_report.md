# Dataset Analysis Report

## 1. Dataset Generation Methodology
Datasets were generated by processing raw PCAP files (`Sample.pcapng`, `Sample2.pcapng`, `Sample3.pcapng`) through the `FlowEngine` utilizing offline `scapy` packet sniffing. This guarantees 100% feature engineering parity with live inference.

## 2. Quantitative Summary
- **Total Processed Flows**: 251,548
- **Missing Values (NaNs)**: 0
- **Duplicate Rows**: 0

## 3. Feature Set
The exact feature pipeline ordered for inference:
1. `duration` (float)
2. `packets_in` (float)
3. `packets_out` (float)
4. `bytes_in` (float)
5. `bytes_out` (float)
6. `avg_packet_size` (float)
7. `packet_rate` (float)
8. `byte_rate` (float)

All features have been validated to be strictly numeric (`float64`) and deterministic.

## 4. Constant / Near-Zero Variance Analysis
No constant features were detected across the 251,548 flows. All features exhibited sufficient variance for unsupervised scaling.

## 5. Dataset Integrity Verification
The strict feature order check script (`validate_dataset.py`) passed successfully against all multi-batch datasets (`dataset_pcap_0.csv`, `dataset_pcap_1.csv`, `dataset_pcap_2.csv`). Hash-based integrity checks for the dataset have been successfully linked to the model artifacts via `metadata.json`.
